TR
Kullanıcıların kolay kullanabileceği bir Grafik Kullanıcı Arayüzüne (GUI) sahiptir. Python kullanılarak yazılmıştır. IP adreslerine ve Asset Name (ana bilgisayar adları) ping gönderilebilir. CmRc ve UltraVNC ile uzak bağlantı yapılabilir. Excel listesi üzerinden IP Adresleri ve Bilgisayar Hostname bilgileri çekilir. Program yönetici ayrıcalıklarıyla çalıştığı sürece uzaktan kapatma ve yeniden başlatma işlemleri uygulanabilir. Bu program işletme ihtiyaçlarına göre tasarlanmış, UltraVNC parolası programın kodlarına gömüldüğü için tek tık ile parolasız bağlantı yapılabilir. Açık ve Koyu tema olarak seçenekler mevcuttur. Kullanıcılar özel klasörler oluşturabilir ve Excel listesindeki bağlantıları favorilere ekleyip daha kolay bağlantı yapılabilir.


EN
It has a Graphical User Interface (GUI) that users can easily use. It is written using Python. Pings can be sent to IP addresses and Asset Name (host names). Remote connection can be made with CmRc and UltraVNC. IP addresses and computer hostname information are extracted from the Excel list. As long as the program is running with administrator privileges, remote shutdown and restart operations can be performed. This program is designed according to business needs; since the UltraVNC password is embedded in the program's code, a password-free connection can be established with a single click. There are options for Light and Dark themes. Users can create custom folders and add links from the Excel list to favorites for easier linking.
